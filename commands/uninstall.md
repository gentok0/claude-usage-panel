---
description: Убрать расширение панели из VS Code (и, по флагу --data, накопленные данные)
argument-hint: "[--data] [--dry-run]"
allowed-tools: Bash
---

Убери то, чего не уносит `/plugin uninstall`: запусти `node "${CLAUDE_PLUGIN_ROOT}/scripts/uninstall.mjs" $ARGUMENTS` и покажи вывод.

Без флагов скрипт удаляет только расширение VS Code, данные оставляет. С `--data` он удаляет и накопленный архив расхода — **это необратимо**: за периоды, которые Claude Code уже подчистил, данных не останется нигде. Перед удалением скрипт печатает, сколько месяцев и на какую сумму лежит в архиве.

Если человек просит «удалить всё», а `--data` не передан — покажи вывод и спроси, удалять ли данные, прежде чем запускать с этим флагом.

После успешного запуска напомни две команды клиента, которые уберут сам плагин: `/plugin uninstall usage-panel@<витрина>` и `/plugin marketplace remove <витрина>`, — и что для VS Code нужен `Developer: Reload Window`.
