---
description: Развернуть панель расхода в VS Code (копирует расширение в профиль)
argument-hint: "[--dry-run]"
allowed-tools: Bash
---

Разверни расширение VS Code для панели расхода: запусти `node "${CLAUDE_PLUGIN_ROOT}/install.mjs" $ARGUMENTS` и покажи вывод.

Скрипт копирует папку расширения в профиль VS Code. Настройки клиента он не трогает: ни один ключ в `settings.json` не добавляется и не меняется. С `--dry-run` он только печатает, что сделал бы.

Если запуск прошёл, скажи одной строкой: панель появится в нижней панели VS Code после команды `Developer: Reload Window`.

Если `node` не найден, скажи, что нужен Node 18+ в `PATH`. Если VS Code на машине нет, скрипт пропускает этот шаг — скилл `usage-analysis` и сбор данных работают и без него.
